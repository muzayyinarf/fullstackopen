# Exercise 0.6: New note in Single page app diagram

Sequence diagram depicting the situation where the user creates a new note using the single-page version of the app at `https://studies.cs.helsinki.fi/exampleapp/spa`:

```mermaid
sequenceDiagram
    participant browser
    participant server

    Note right of browser: The user writes text into the input field and clicks the "Save" button

    Note right of browser: The event handler in spa.js prevents the default form submission (e.preventDefault()),<br/>adds the new note to the local notes list, re-renders the notes on the page,<br/>and sends the new note to the server as JSON

    browser->>server: POST https://studies.cs.helsinki.fi/exampleapp/new_note_spa (JSON payload: { content: "...", date: "..." })
    activate server
    Note left of server: The server saves the new note without redirecting
    server-->>browser: HTTP 201 Created ({"message":"note created"})
    deactivate server
```
